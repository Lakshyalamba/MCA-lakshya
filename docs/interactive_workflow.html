Five technical owners

How the project is divided among us

Each member must contribute implementation or verifiable engineering artefacts and explain the complete prediction flow in the interview.

P1

2-bit predictor + Branch History Table · You

Own 16-entry counter storage, BHT indexing, reset, update logic, saturation and aliasing tests.

Proof: predictor_2bit.v, branch_history_table.v, P1 tests, waveform, PR.
P2

Branch Target Buffer

Own target cache, valid/tag lookup, update and replacement behavior for the chosen design.

Proof: branch_target_buffer.v, standalone BTB tests, PR.
P3

Next-PC logic + pipeline recovery

Own target selection, direction/target mismatch comparison, flush and redirect interface, integration.

Proof: branch_resolution.v, interface tests, integration PR.
P4

1-bit baseline + verification

Own baseline comparison, generated BEQ/BNE traces, independent reference model and regression tests.

Proof: predictor_1bit.v, traces, automated tests, PR.
P5

Performance + synthesis + documentation

Own measured accuracy tables, CPI model assumptions, Yosys reports, figures and report/video assembly.

Proof: comparison output, scripts, IEEE draft, synthesis artefacts, PR.
Contribution rules

Keep the GitHub history authentic

Use feature branches and small pull requests for independently reviewed work. Include the tests and a short evidence note with each component. Never manufacture commits or claim someone implemented a module they did not work on. Each member should be able to explain their own Verilog signals and at least one full end-to-end branch example.
